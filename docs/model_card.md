# Model Card — NSCLC Radiomics Survival Models

## Overview

This repository implements 17 deep-learning survival analysis experiments
(E1–E17d) on the TCIA **Lung1 cohort** (n=422, Aerts et al. 2014).
Models predict overall survival from 3-D CT images and/or clinical variables
using Cox partial likelihood.

## COLIPRI Pretraining Data

**Relevant to experiments E16a/b and E17a/b/c/d.**

`microsoft/colipri` (Wald et al., *Comprehensive Language–Image Pre-training
for 3D Medical Image Understanding*, ECCV 2026) is pretrained on two documented
corpora:

- **CT-RATE** — 25,692 chest CT volumes paired with radiology reports
  (Istanbul Medipol University Hospital); used for the contrastive, report-
  generation, and masked-image objectives.
- **NLST** — ~72,000 image-only chest CT scans (US National Lung Screening
  Trial); used for the masked-image (vision-only) objective.

**The NSCLC-Radiomics / Lung1 cohort used in this study is not part of either
corpus.** Lung1 originates from MAASTRO Clinic (Maastricht) and is distributed
through TCIA; it shares no patients with CT-RATE or NLST. The COLIPRI results
here are therefore **not** affected by pretraining/test overlap.

**Caveats that do apply** (and are not leakage):

1. COLIPRI was pretrained on a chest-CT distribution that differs from Lung1
   (scanner, protocol, population), so some domain shift is expected.
2. All results are from a single site (n = 422); **external validation on an
   independent cohort remains necessary** before any generalisation claim.
3. The comparison to Paolo et al. (2026) mixes metrics: this study reports
   Harrell's C, whereas Paolo report a time-dependent concordance. The numbers
   are indicative, not strictly like-for-like.

## Intended Use

- **Primary use**: Research reproducibility companion for NSCLC radiomics thesis.
- **Not for clinical use**: No prospective validation; results on n=422 single-site
  cohort. High event rate (88.4%) limits generalisability.
- **Evaluation**: OOF C-index only; no external validation cohort.

---

## Ethical Considerations

- Patient data: TCIA Lung1 is a public dataset requiring TCIA DUA agreement.
  No raw patient data is included in this repository.
- Model predictions should not be used for clinical decision-making.

Pre-trained checkpoints (E1–E17d, all folds) are **not yet published**. Once
uploaded to the Hugging Face Hub, this section will give the exact repository

    repo_id="<your-hf-username>/nsclc-survival-checkpoints",

```bash

    repo_id="<your-hf-username>/nsclc-survival-checkpoints",  # placeholder — not yet published
    filename="E17d_fold01.pt",

```
