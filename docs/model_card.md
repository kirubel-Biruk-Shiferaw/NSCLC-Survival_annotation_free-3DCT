# Model Card — NSCLC Radiomics Survival Models

## Overview

This repository implements 17 deep-learning survival analysis experiments
(E1–E17d) on the TCIA **Lung1 cohort** (n=422, Aerts et al. 2014).
Models predict overall survival from 3-D CT images and/or clinical variables
using Cox partial likelihood.

## ⚠️ COLIPRI Pretraining Data Leakage Caveat

**This is a critical caveat for experiments E16a/b and E17a/b/c/d.**

`microsoft/colipri` was pretrained on a large chest CT corpus paired with
radiology reports. The exact pretraining set has not been publicly documented
by Microsoft at the time of writing. If this corpus includes TCIA data —
which it plausibly does, given TCIA's status as a major public source of
chest CT with associated clinical reports — then:

1. **The COLIPRI encoder has potentially been trained on Lung1 scans.**
2. Radiology reports for Lung1 patients often contain survival-relevant
   information (e.g. staging, prognosis statements).
3. The model may have learned to embed survival-predictive features not from
   the CT signal per se, but from the paired text.

**Implication**: The C-index improvement from ~0.58 (CNN) to ~0.65 (COLIPRI)
**cannot be safely attributed to better 3-D visual feature extraction**.
It may entirely or partially reflect memorisation of the training cohort.

**What this means for downstream use**:
- Do not use COLIPRI C-index values as estimates of generalisation to
  unseen patient populations.
- Future work should validate on an independent cohort (e.g. TCIA HEAD-NECK)
  or use a pretrained model with a documented, Lung1-free pretraining set.

We include the COLIPRI experiments because they are part of the experimental
comparison with Paolo et al. 2026, and because demonstrating the leakage
issue is itself scientifically valuable. All papers citing this work should
reproduce this caveat.

## Intended Use

- **Primary use**: Research reproducibility companion for NSCLC radiomics thesis.
- **Not for clinical use**: No prospective validation; results on n=422 single-site
  cohort. High event rate (88.4%) limits generalisability.
- **Evaluation**: OOF C-index only; no external validation cohort.

---

## Ethical Considerations

- Patient data: TCIA Lung1 is a public dataset requiring TCIA DUA agreement.
  No raw patient data is included in this repository.
- Model predictions should not be used for clinical decision-making.

## Trained Checkpoint Download

Pre-trained checkpoints (E1–E17d, all folds) are available on Hugging Face Hub:

```bash
# Install huggingface_hub
pip install huggingface_hub

# Download all checkpoints (~2.1 GB)
python - <<'EOF'
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id="birukkirubel/nsclc-survival-checkpoints",
    local_dir="outputs/checkpoints",
    repo_type="model",
)
EOF
```

Or download a single fold checkpoint:
```bash
from huggingface_hub import hf_hub_download
hf_hub_download(
    repo_id="birukkirubel/nsclc-survival-checkpoints",
    filename="E17d_fold01.pt",
    local_dir="outputs/checkpoints",
)
```

> **Note**: Checkpoints are uploaded after thesis submission.
> Until then, follow `README.md` to retrain from scratch (~6 hours on one GPU).
